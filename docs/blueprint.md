# **App Name**: AceFolio

## Core Features:

- Profile Creation: Users can create detailed profiles showcasing their skills, experience, and projects.
- Portfolio Showcase: Visually appealing display of projects with descriptions, images, and links.
- Skill Endorsement: Allow other users to endorse skills listed on a profile.
- AI-Powered Resume Generation: Automatically generate a resume based on the user's profile data, with the LLM as a tool used to summarize user qualifications.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) for a professional yet creative feel.
- Background color: Very light gray (#F5F5F5), almost white, to ensure readability and a clean look.
- Accent color: Teal (#009688) to highlight important elements and CTAs.
- Headline font: 'Belleza' sans-serif for a modern, eye-catching aesthetic.
- Body font: 'Alegreya' serif for readability and a premium feel.
- Use a set of professional, minimalist icons for skills and categories.
- Clean and structured layout with clear sections for profile, projects, and skills.
- Subtle transition animations for project displays and profile updates.
